# UI Refresh 设计：车机页面 + Mac 设置窗口

日期：2026-10-15 · 状态：已确认（设计稿见 `.superpowers/brainstorm/`：visual-style / design-webclient-v2 / design-mac-window）

## 目标

- 两个界面统一视觉语言：**白底 + 彩虹渐变点缀**
- 车机页面触控优先（2.5K 横屏为主，手指点按）
- Mac 窗口信息架构重组：长列表 → 顶部 4 Tab

## 非目标

- 不改串流/协议/心跳/缓冲逻辑（状态接口已齐备）
- 不增删设置项集合，仅重组（唯一新增行为：跟随系统深色自动变暗）

## 设计 Tokens

- 彩虹渐变：`linear-gradient(135deg,#ff5f6d,#ffb26b,#ffe66b,#6bd47f,#4fc3f7,#b06bf5)`
- 车机页面：外圈 `#f5f6f8`、卡片/面板 `#fff`、主文字 `#1a1a1a`、次要 `rgba(0,0,0,.4)`
- 警示（断连/冲突/USB 接口）：`#ff9500` 系
- 彩虹只用于「点」：激活态、主按钮、滑杆填充、转圈、状态卡；大面积保持白/浅灰

## Part 1 · 车机页面（webclient.html）

1. **控制按钮** 🔊 ⛶ ⚙️：emoji → 内联 SVG 线性图标；40×40 圆形，深色画面上白底 `rgba(255,255,255,.92)` + blur + 柔和阴影；⚙️ 面板开启时彩虹渐变底 + 白图标；按下 active `scale(.92)`
2. **设置面板**：白色毛玻璃 `rgba(255,255,255,.94)` 圆角 16 阴影，分段控件三 Tab：
   - 显示：分辨率（触控行 ›）、帧率（30/60 分段块）、UI 缩放、匹配本窗口像素、应用显示设置（彩虹主按钮）、安全边距 4 滑杆
   - 音频：总音量/媒体/导航/通话 4 条彩虹渐变滑杆
   - 麦克风：启用大按钮（激活红色态）+ 说明
3. **等待页**：白底全屏、彩虹双段转圈（`border-top #b06bf5` `border-right #4fc3f7`）、主/副两行文案
4. **断连横幅**：顶部居中橙色 pill（`#fff3e0` 底 / `#ffcf99` 边 / `#ff9500` 点）「连接已断开 · 重连中」，WS 断开显示、恢复淡出；纯 UI，重连逻辑不动
5. **提示条**：「触摸屏幕操作 CarPlay · 双击呼出/隐藏控制」6s 自动淡出
6. **HUD**：浅色毛玻璃底 + 深色 monospace 文字
7. **夜间**：`prefers-color-scheme: dark` 时 chrome 整体切深色（画面区不变），无手动开关
8. **专注模式**：保留现逻辑（`body.focus` 隐藏全部 UI，双击切换）
9. 面板开合 150ms opacity+scale 过渡

## Part 2 · Mac 设置窗口（MacPlay.swift）

1. **结构**：顶部 4 Tab（连接 / 显示 / 音频 / 关于），默认窗口约 560×540
2. **连接 Tab**：
   - 会话状态卡（浅渐变底）：圆点绿/橙/灰、设备名、USB/WiFi、会话时长、当前分辨率帧率
   - 车机浏览器地址卡：每接口一行（HTTPS 主行大字 + 彩虹复制主按钮；HTTP 行次要 + 描边按钮），接口标签 Wi-Fi 绿 / iPhone USB 橙警示；同网段冲突橙色警告条；保留 10s 自动刷新
   - 防火墙卡：未放行 → 彩虹「一键放行」主按钮；已放行 → 绿色 ✓
   - WiFi 密码卡：已保存数量 + 管理入口（SSID 列表展开/删除）
3. **显示 Tab**：分辨率、帧率、编码、UI 缩放、安全边距（现有控件平移）
4. **音频 Tab**：输出/输入设备、音量、通话音量、「打开浏览器时自动恢复播放」
5. **关于 Tab**：版本、构建、设备 ID、GitHub 链接
6. **视觉**：保持 macOS 原生控件不重皮肤；若原生 TabView 无法定制彩虹下划线，接受原生样式降级（彩虹仅用于按钮/状态卡）

## 边界情况

- 断连横幅 z-index 低于面板，物理位置错开（横幅顶部居中、面板右侧），不互相遮挡
- 按钮/面板 touch 事件 `stopPropagation`，不透传到 CarPlay 触摸（保留现有逻辑）
- 地址列表为空：显示「等待网络…」占位行
- 麦克风开启中：面板内按钮红色激活态
- 夜间切换 200ms 过渡

## 测试

- 车机 Android 浏览器 2.5K：触控目标 ≥40px、面板 Tab 切换、断连横幅出现/消失、双击专注模式
- Mac Safari/Chrome：视觉回归、`prefers-color-scheme` 跟随
- SwiftUI：四 Tab、地址复制、防火墙状态、冲突警告、本地化（简/繁/英）
- 回归：触摸透传、HUD 数据、AudioContext 手势解锁提示不被新 UI 挡住
